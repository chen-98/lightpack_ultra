LighterPack contributing guide
===========
Thanks for your interest in contributing to LighterPack!

This fork is currently focused on beta release stabilization, maintenance, and small improvements to the existing Vue 2 application.

Before contributing, review `AGENT.md`, `docs/working-agreement.md`, `docs/product-philosophy.md`, and `docs/modernization-plan.md` so changes stay small, traceable, and aligned with the current release scope.

The most useful contributions for the beta are focused bug fixes, documentation fixes, and small changes that improve core packing-list workflows without changing saved library JSON.
